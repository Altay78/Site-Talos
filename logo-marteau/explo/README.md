# Pistes — marteau + éclair fusionnés, toit orienté tech

Exploration, **rien n'est validé**. Le logo de production reste le dossier parent.

## Ce qui change

**1. Fusion marteau + éclair.** Le manche du marteau *est* l'éclair : une seule silhouette
continue (tête à griffe + manche en zigzag terminé en pointe) au lieu de deux formes
superposées avec une respiration entre elles. Plus besoin de découpe entre les deux : ils ne
se croisent plus, ils se prolongent. Gain net en mono, où le mark lisait avant comme deux
objets collés.

**2. Six traitements du toit** pour faire entrer la tech sans perdre le bâtiment :

| | Piste | Lecture |
|---|---|---|
| A | `dissolution` | le toit est plein au centre et se disperse en segments vers les extrémités — la matière devient données |
| B | `segments` | toit en segments réguliers — rythme numérique, silhouette du toit intacte |
| C | `circuit` | tracé fin + pastilles aux extrémités et au sommet — circuit imprimé |
| D | `signal` | deux chevrons emboîtés — diffusion, propagation |
| E | `agent` | toit plein + un point au-dessus du sommet — la balise, l'agent qui veille |
| F | `module` | demi-hexagone — puce, module |
